Mockup v2 changelog

What changed and why

Updates from v1 · April 30

Today is now schedule-first

Left column leads with a time-blocked schedule (8:30 AM → 5:30 PM) showing exactly what to work on, in what order, for how long. Color-coded markers: red = fixed, blue = flex, purple = deep work, green = in progress. The schedule earns the prime real estate because that's the question you're asking at 8 AM.

Block types carry meaning

Each block shows: time, duration, title, one-line description, and tags (tier C / draft ready / linked / etc). You can see at a glance which blocks only YOU can do (red Tier C tags) vs which are review-style work (blue draft ready).

Reflow on slip

"Reflow schedule" button at the top. If you fall behind, the agent reorders the rest of the day instead of leaving you with a stale plan. Buffer block at end of day absorbs drift. Configurable in Insights settings.

Linked actions: reply + spawn

The TravelDom influencer email is the canonical example. Agent detects "this email implies team work" and surfaces both a reply draft AND a spawned task for Oscar — with full brief, rate sheet context, and clear next steps. Approve both with one tap, edit either side, or split.

Linked is visually distinct

Purple is the new color reserved for linked/coupled actions. Purple banner across the top of the approval card. Purple left border on the spawning email in the inbox. Purple chip in tags. Easy to spot, never confused with a regular Tier B draft.

Project detail shows everything

Click a project from the list and you get: hero with description and meta, progress bar with pace, agent recommendation in red callout, fully sequenced milestone list with status (complete / in-progress / overdue / blocked / waiting), agent observations sidebar, and recent activity feed. The Fareharbor migration tells its own story when laid out this way.

Team detail has substance

Click into Nick: hero with channel preference, 5 stats (open / avg reply / completion / total / projects), responsibilities list, learned style block, and recent task history. This is how you'd reload context before sending him something important.

Insights has 4 sub-tabs

Weekly (the pattern detections) · Monthly (cross-cutting strategy synthesis with month-in-review) · SOPs (active library with usage counts) · Settings (schedule timing, linked-action thresholds, run cadences, etc).

Schedule on mobile is glanceable

Mobile schedule shows the same day with tighter density — time column, color marker, title, description. Same color logic. NOW block highlighted in green. Scrollable inside the daily card without taking over the whole screen.
